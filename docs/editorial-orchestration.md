# Editorial workflow / menselijke goedkeuring

Pipeline: SELECT ONE PAGE → AUDIT → RESEARCH → EVIDENCE REGISTER → BRIEF → DRAFT → HUMANIZER → GENERAL-WRITING → ANTI-AI-SLOP → FACT CHECK → LINK REVIEW → SEO REVIEW → IMAGE DECISION → EDITORIAL QA → PUBLISH REVIEW → COMMIT → AWAIT MANUAL APPROVAL.

Duid per stap aan of die werkelijk uitgevoerd of geblokkeerd is. De bronworkflows komen uit bloc-notes-numerique en moeten voor een nieuwe inhoudelijke categorie aan domein-specifieke feiten aangepast worden.

Start met alleen de homepage. Na goedkeuring de volgende pagina `/moestuin-beginnen/`. Drafts zonder gecontroleerde inhoud blijven noindex.
